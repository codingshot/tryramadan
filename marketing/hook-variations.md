## Quick reference — when to use which

| Category | Best for |
|----------|----------|
| Pattern Interrupt | Feeds, strong skepticism, "too many apps" fatigue |
| Curiosity Gap | Engagement, shares, comments |
| Authority Play | Trust, app store, landing pages |
| Data-Led | Performance ads, "productivity" / "hack" angles |
| Story Entry | Reels, TikTok, longer captions, emotional connection |
